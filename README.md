# Modelos-IA

Aplicação web simples para preparar vídeos com modelos/personagens de IA.

## Objetivo inicial

- Interface mobile-first
- Prompt de vídeo
- Imagem de referência
- Duração e proporção
- Área de criações recentes

> Nesta primeira etapa, a interface é apenas visual. A geração real será integrada posteriormente, após escolher um provedor compatível e revisar custos e políticas.

## Executar localmente

```bash
npm install
npm run dev
```
